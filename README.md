# 睡眠周期

一个单文件的睡眠时间计算器。基于「90 分钟一个睡眠周期」这一常见假设，在「想起床的时间」和「该上床的时间」之间互相推算。

整个项目只有一个 `index.html`，没有构建步骤，没有依赖，没有任何网络请求。用浏览器直接打开即可运行。

## 功能

- **由起床推算上床**：输入你希望起床的时刻，列出往前推 4 / 5 / 6 个周期对应的上床时间。
- **由上床推算起床**：输入你打算上床的时刻，列出往后推 4 / 5 / 6 个周期对应的起床时间。
- **显示更多选项**：展开后可选 3 到 8 个周期，覆盖更短或更长的睡眠时长。
- **入睡时间**：指从躺到床上到真正睡着所需要的时间，用于把「上床时刻」换算成「睡着时刻」。默认 15 分钟，范围 0 到 60 分钟。
- **年龄段**：按发育阶段与生活状态分为 21 档，每档给出建议睡眠时长，用于挑选更合适的周期数。默认 22–35 岁。
- **相对时间**：每张卡片除了绝对时刻，还会显示「距离上床还有 X 小时 X 分钟」，或者目标时刻已过时显示「已经过去 X 小时 X 分钟」。
- **跨天标记**：落在前一天晚上的时刻标注「前一晚」，落在第二天的标注「次日」。

## 使用

直接双击 `index.html`，或者把它放到任意静态服务器上。

```
index.html
```

也可以在手机浏览器里打开。页面已适配从 320px 到宽屏的各种宽度。

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架、无构建、无依赖。
- 时钟选择器是自己实现的滚动轮，支持鼠标滚轮、键盘方向键、Home / End，以及点击选项直接跳转。
- 时间计算全部用「当天第几分钟」做整数运算，跨天判断基于钟点差，避免日期时区带来的偏差。
- 图标为内联 SVG，不加载任何外部资源。
- 已适配 `prefers-reduced-motion`，在系统开启「减少动态效果」时动画会被压缩到几乎瞬时。
